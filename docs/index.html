Ensconce

Hide the apps that won't hide. Every running app with a window, one button each — and the stubborn ones get tucked away regardless.

Download for macOS Requires macOS 14.0 or later •
🪟

One Row Per Process

Every app that owns a window, with a Hide or Show button. Two copies of the same app stay separate, because they hide independently.

🫥

Verified Hiding

Five strategies tried in order, each checked against the window server. An app counts as hidden only when none of its windows is on a display.

🧊

Freeze When Hidden

Optionally stop a hidden app cold so it can't bring itself back. Show thaws it again; frozen apps do no background work.

🔍

Get Info

Highlight a row and press ⌘I for its pid, bundle ID, executable, hide state, and every window with its bounds.

🧹

Noise Filtered

macOS helpers — loginwindow, XPC view services, WebKit content — stay out of the list until you ask for them from the View menu.

🔒

No Screen Recording

Window titles come from Accessibility, never from screen capture. Regular apps hide with no permissions at all.

How it hides

Each strategy is verified against the window server before Ensconce moves on; a failed attempt is rolled back first, and if all of them fail the row says exactly what was tried.

The real ⌘H — NSRunningApplication.hide().
AXHidden on the application, which reaches agent apps AppKit refuses.
System Events set visible to false.
AXMinimized on every window.
Park every window beyond all displays, remembering each frame.
